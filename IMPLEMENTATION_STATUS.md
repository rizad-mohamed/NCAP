## Adapter boundary

The local release uses versioned, section-recovering local JSON state and IndexedDB media. A concrete local repository adapter now supplies typed collections through a provider, while TanStack Query hooks consume authoritative snapshots and mutation methods. Normalized API errors, no-op telemetry, a focused session/preferences context, and an in-memory auth contract define the injection boundary. Switching to a real API remains **BACKEND REQUIRED** and must not weaken the explicit demo labels or UX-only guard messaging.
